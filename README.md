# Vectora

Кроссплатформенный векторный редактор на **C++17 и Qt 6** (Qt Widgets).
Рабочее название проекта, легко меняется.

Текущий этап — **интерфейсный прототип**: собраны меню, панели инструментов,
панель свойств, линейки, док-панели объектов и свойств, палитра цветов,
холст с пробной страницей A4. Команды, которые ещё не реализованы, честно
пишут об этом в статус-баре.

## Сборка (Linux)

Нужны CMake ≥ 3.21, компилятор C++17 и Qt 6 (Base, Widgets, Svg, PrintSupport).

Arch / CachyOS / Manjaro:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg
```

Debian / Ubuntu (24.04+):

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
```

Fedora:

```bash
sudo dnf install gcc-c++ cmake qt6-qtbase-devel qt6-qtsvg-devel
```

Сборка и запуск:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/vectora
```

Или просто:

```bash
./run.sh
```

`run.sh` соберёт проект при первом запуске и запустит приложение.

## Что уже работает

- Тёмная тема, меню и две панели инструментов.
- 21 инструмент в левой панели с подсказками и горячими клавишами.
- Панель свойств, которая меняется под выбранный инструмент
  (геометрия / текст / заливка / масштаб).
- Линейки в миллиметрах, синхронизированные с холстом и масштабом.
- Холст: страница A4, сетка, область печати, тень.
- Масштаб: `Ctrl + колесо`, кнопки, поле ввода, «по странице», 100 %.
- Панорама: средняя кнопка мыши, пробел или инструмент «Панорама».
- Выделение всех объектов (`Ctrl+A`) и удаление (`Del`).
- Палитра цветов с подсказками; выбор цвета показывается в статус-баре.
- Док-панели «Объекты и слои» и «Свойства», их можно скрывать через «Окно».
- Диалоги «Горячие клавиши» (`Ctrl+F1`) и «О программе».

## Что пока заглушки

Создание и сохранение документов, рисование фигур, редактирование узлов,
заливки и обводки, эффекты, импорт/экспорт SVG/PDF, буфер обмена.
Кнопки и пункты меню уже есть — они сообщают о следующем этапе в статус-баре.

## Горячие клавиши (основное)

| Клавиши | Действие |
| --- | --- |
| `V` / `N` | Выделение / редактирование узлов |
| `R` / `E` / `P` | Прямоугольник / эллипс / многоугольник |
| `Shift+P` / `Shift+S` | Звезда / спираль |
| `L` / `B` / `F` | Линия / кривая Безье / свободная форма |
| `T` | Текст |
| `Z` / `H` | Масштаб / панорама |
| `Ctrl + колесо` | Масштаб под курсором |
| `Пробел` (удерживать) | Панорама |
| `Ctrl+0` / `Ctrl+1` | По странице / 100 % |
| `Ctrl+A` / `Del` | Выделить всё / удалить |
| `F11` | Полноэкранный режим |

Полный список — в меню «Справка → Горячие клавиши».

## Структура

```
src/
  main.cpp          точка входа, разбор --screenshot
  MainWindow.*      меню, панели, доки, статус-бар, пробный документ
  CanvasView.*      холст, страница, сетка, масштаб, панорама
  Ruler.*           линейки в миллиметрах
  ToolPalette.*     левая панель инструментов
  ColorPalette.*    нижняя палитра
  Icons.*           векторные иконки, рисуемые кодом (без внешних ассетов)
  Theme.*           тёмная тема и QSS
  Tools.h           перечисление инструментов и их метаданные
```

## Служебное

Скриншот интерфейса без открытия окна:

```bash
QT_QPA_PLATFORM=offscreen ./build/vectora --screenshot /tmp/vectora.png
```

## Windows и macOS

Код и CMake-проект кроссплатформенные. Для сборки достаточно Qt 6 и CMake:

- **Windows**: Qt Online Installer (MSVC 2022 + Qt 6), затем
  `cmake -S . -B build -G "Visual Studio 17 2022" -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/msvc2022_64`.
- **macOS**: `brew install qt cmake`, затем
  `cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"`.

Упаковка (AppImage/Flatpak, MSI/MSIX, DMG с подписью) — отдельный этап.
