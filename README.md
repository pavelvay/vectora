# Vectora

Кроссплатформенный векторный редактор на **C++17 и Qt 6** (Qt Widgets).
Рабочее название проекта, легко меняется.

Второй этап: **рабочий документ, файловые операции и все инструменты левой панели**.
Интерфейс, заливки, текст, узлы, тень, перетекание, обрезка, Undo/Redo и экспорт
уже работают. Эффекты, группы и слои пока остаются заглушками.

## Сборка (Linux)

Нужны CMake ≥ 3.21, компилятор C++17 и Qt 6 (Base, Widgets, Svg, PrintSupport).

Arch / CachyOS / Manjaro:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg
```

Debian / Ubuntu (24.04+):

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
```

Fedora:

```bash
sudo dnf install gcc-c++ cmake qt6-qtbase-devel qt6-qtsvg-devel
```

Сборка и запуск:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/vectora
```

Или просто `./run.sh` — соберёт при первом запуске и откроет редактор.

## Файлы

- **Создать** `Ctrl+N` — новый документ A4.
- **Открыть / Сохранить / Сохранить как** — собственный формат `.vct`
  (JSON с геометрией, цветами, шрифтами и изображениями).
- **Импорт** — PNG, JPG, BMP, SVG. SVG импортируется как изображение
  (растеризуется), а не как редактируемые кривые.
- **Экспорт** — PNG с двойным разрешением или SVG с настоящими путями и текстом.
- **Экспорт в PDF** — страница A4 без полей.
- **Печать** — системный диалог печати.
- **Undo/Redo** — до 100 шагов, включая перемещение, размеры, поворот,
  текст, заливку и удаление.

## Инструменты левой панели

| Инструмент | Что делает |
| --- | --- |
| Выделение `V` | выбор, перемещение, 8 маркеров размера, поворот за верхний круг |
| Форма `N` | редактирование узлов: опорные точки и управляющие точки кривых |
| Обрезка `C` | рамкой обрезает пути объектов |
| Прямоугольник `R` | протяжка, `Shift` — квадрат |
| Эллипс `E` | протяжка, `Shift` — круг |
| Многоугольник `P` | от центра, 6 сторон |
| Звезда `Shift+P` | от центра, 5 лучей |
| Спираль `Shift+S` | от центра, 3 оборота |
| Линия `L` | протяжка, `Shift` — 45° |
| Кривая Безье `B` | клики добавляют узлы, протяжка задаёт кривизну, `Enter`/двойной клик — готово |
| Свободная форма `F` | рисование от руки со сглаживанием |
| Художественное перо `A` | толстый живописный мазок цветом заливки |
| Текст `T` | клик создаёт текст, диалог ввода; двойной клик — правка |
| Пипетка `I` | берёт цвет с холста в текущую заливку |
| Заливка `G` | клик по объекту заливает текущим цветом |
| Обводка `O` | диалог цвета и толщины для объекта |
| Прозрачность `Shift+T` | клик и протяжка влево/вправо меняют прозрачность |
| Тень `Shift+D` | клик включает/выключает тень объекта |
| Перетекание `Shift+B` | для двух выделенных объектов создаёт 7 промежуточных |
| Масштаб `Z` | клик — увеличить, правый клик — уменьшить |
| Панорама `H` | перетаскивание холста (или средняя кнопка / пробел) |

Цвета: палитра снизу задаёт заливку; если объекты выделены, цвет применяется
к ним. Два квадрата внизу слева открывают выбор цвета заливки и обводки.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` | создать / открыть |
| `Ctrl+S` / `Ctrl+Shift+S` | сохранить / сохранить как |
| `Ctrl+I` / `Ctrl+E` | импорт / экспорт |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | вырезать / копировать / вставить |
| `Ctrl+D` / `Del` | дублировать / удалить |
| `Ctrl+A` | выделить всё |
| `Ctrl + колесо` | масштаб под курсором |
| `Ctrl+0` / `Ctrl+1` / `Ctrl+2` | по странице / 100 % / по выделению |
| `Ctrl+R` | линейки |
| `F11` | полный экран |

Полный список — в меню «Справка → Горячие клавиши» (`Ctrl+F1`).

## Что пока не реализовано

- Группировка, слои, порядок наложения и выравнивание (меню «Объект»).
- Эффекты: оболочка, экструзия, линза, скос (меню «Эффекты»).
- Направляющие и реальная привязка (галочки в меню пока декоративные).
- Панель «Свойства» показывает пример, а не выбранный объект.
- Импорт CDR и редактируемый импорт SVG.
- Inline-редактирование текста на холсте (сейчас диалог).

## Тесты

Автотест проверяет сохранение/загрузку `.vct`, экспорт PNG/SVG/PDF,
рисование фигур, заливку, узлы, тень, перетекание и Undo/Redo:

```bash
QT_QPA_PLATFORM=offscreen ./build/vectora --self-test /tmp/vectora-test
```

Результат: `PASSED` и набор файлов в каталоге.

## Служебное

```bash
./build/vectora --open файл.vct                 # открыть документ
QT_QPA_PLATFORM=offscreen ./build/vectora \
  --screenshot /tmp/vectora.png                 # снимок интерфейса
```

## Структура

```
src/
  main.cpp          точка входа и служебные флаги
  Document.*        модель объектов, .vct, SVG, рендер страницы
  VectorItem.*      графический объект: рисование, маркеры, поворот
  CanvasView.*      холст, инструменты, узлы, предпросмотр, история
  MainWindow.*      меню, файлы, панели, статус-бар, Undo/Redo
  Ruler.*           линейки в миллиметрах
  ToolPalette.*     левая панель инструментов и индикатор цветов
  ColorPalette.*    нижняя палитра
  Icons.*           векторные иконки, рисуемые кодом
  Theme.*           тёмная тема и QSS
  Tools.h           перечень инструментов
  SelfTest.*        автотесты
```

## Windows и macOS

Код и CMake-проект кроссплатформенные. Для сборки достаточно Qt 6 и CMake:

- **Windows**: Qt Online Installer (MSVC 2022 + Qt 6), затем
  `cmake -S . -B build -G "Visual Studio 17 2022" -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/msvc2022_64`.
- **macOS**: `brew install qt cmake`, затем
  `cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"`.

Упаковка (AppImage/Flatpak, MSI/MSIX, DMG с подписью) — отдельный этап.
