# Vectora

Кроссплатформенный векторный редактор на **C++17 и Qt 6** (Qt Widgets).
Рабочее название проекта, легко меняется.

Версия **0.2.2**: докер «Библиотека» скрыт на стартовой странице и
появляется только в редакторе; остальное — профессиональные эффекты,
символы и библиотека ресурсов, точное черчение, паттерны, QR/штрихкоды,
управление документами и проверка обновлений с GitHub.

## Установка

Готовые сборки публикуются в GitHub Releases: Windows-установщик, Linux
AppImage и `.deb`, macOS DMG.

- **Windows**: скачайте `Vectora-0.1.11-Setup.exe` и запустите. Сборка не
  подписана, поэтому SmartScreen может показать предупреждение:
  «Подробнее» → «Выполнить в любом случае».
- **Linux AppImage**: `chmod +x Vectora-0.1.11-x86_64.AppImage` и запустите.
  Если нет FUSE: `./Vectora-0.1.11-x86_64.AppImage --appimage-extract-and-run`.
  AppImage использует X11/XWayland; при необходимости задайте
  `QT_QPA_PLATFORM=xcb`.
- **Debian/Ubuntu**: `sudo apt install ./Vectora-0.1.11-amd64.deb`.
- **Arch/CachyOS**: `packaging/PKGBUILD` — `makepkg -si`.
- **macOS (Apple Silicon)**: откройте DMG и перетащите Vectora в Applications.
  Сборка не подписана: правый клик → «Открыть» или
  `xattr -dr com.apple.quarantine /Applications/Vectora.app`.
  DMG собран для arm64 (Apple Silicon); для Intel Mac нужна отдельная сборка.

Сборки создаются автоматически в GitHub Actions.

## Сборка (Linux)

Нужны CMake ≥ 3.21, компилятор C++17 и Qt 6 (Base, Widgets, Svg, PrintSupport).

Arch / CachyOS / Manjaro:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg
```

Debian / Ubuntu (24.04+):

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
```

Fedora:

```bash
sudo dnf install gcc-c++ cmake qt6-qtbase-devel qt6-qtsvg-devel
```

Сборка и запуск:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/vectora
```

Для локальной проверки используйте `./run.sh` — он **всегда пересобирает
локально** изменённый код и запускает приложение, ничего не публикуя:

```bash
./run.sh                 # Release-сборка + запуск
./run.sh --debug         # Debug-сборка + запуск
./run.sh --test          # автотесты без окна
./run.sh --no-build      # запустить уже собранный бинарник
./run.sh --clean         # очистить build/ и собрать заново
```

Скрипт никогда не создаёт теги, релизы и не выгружает файлы на GitHub.
Публикация выполняется только по отдельному запросу на сборку.

## Кривая Безье

Поведение инструмента:

- **Клик** ставит узел; **протяжка** от узла задаёт кривизну сегмента.
- **Alt** при протяжке делает узел тупым (направляющие независимы).
- **Ctrl** ограничивает направляющую шагом 15°.
- **Backspace** удаляет последний узел.
- **Клик по первому узлу** замыкает кривую (узел подсвечивается).
- **Enter** или **двойной клик** завершает открытую кривую.
- **Esc** отменяет построение.
- В панели свойств сверху выбирается тип нового узла:
  тупой, сглаженный или симметричный; есть «Автозамыкание»,
  «Замкнуть», «Удалить узел» и «Завершить».
- Замкнутая кривая получает заливку, открытая остаётся контуром.

## Докеры справа

Все панели докируемые, с вкладками. Снизу справа — группы вкладок,
сверху список объектов.

| Докер | Что делает |
| --- | --- |
| **Объекты** | слои, **вложенные группы**, объекты; перетаскивание, видимость, замки слоёв и объектов |
| **Свойства** | X, Y, ширина, высота, угол, прозрачность, заливка, обводка, толщина — применяются сразу; прозрачность в реальном времени |
| **Цвет** | оттенок/насыщенность/яркость/альфа и HTML-код; заливка применяется сразу, ЛКМ по образцу — заливка, ПКМ — обводка |
| **Выравнивание** | 6 выравниваний относительно выделения или страницы, распределение по горизонтали и вертикали |
| **Эффекты → Тень** | включение, сдвиг X/Y, непрозрачность, цвет тени |
| **Эффекты → Прозрачность** | прозрачность выделения, применяется сразу при движении ползунка |
| **Эффекты → Перетекание** | 2–40 промежуточных копий между двумя объектами |
| **Обводка** | цвет, толщина, окончания, соединения, miter-limit, пунктир; преобразование обводки в кривую |
| **Текст** | шрифт, кегль, полужирный/курсив/подчёркивание, выравнивание |

Верхняя панель быстрых свойств синхронизирована с выделением.

## Параметры фигур

Для инструментов фигур верхняя панель показывает параметры:

- **Прямоугольник** — скругление углов;
- **Многоугольник** — число сторон (3–64);
- **Звезда** — число лучей и острота;
- **Спираль** — число витков.

Значение применяется к выделенным фигурам этого типа и запоминается
для новых. Размер фигуры при смене параметра сохраняется.

## Выделение объектов

- Угловой маркер масштабирует **пропорционально**; боковой — свободно.
  `Shift` при протяжке угла отключает пропорции.
- `Ctrl` (или `Shift`) при повороте фиксирует угол кратно 15°.
- `Alt+клик` выбирает объект **под** верхним; повторный Alt+клик уходит глубже.
- `Tab` перебирает объекты сверху вниз.
- Двойной клик по инструменту **«Выделение»** выбирает все объекты.
- `Ctrl+V` вставляет объект **точно на исходное место**.
- `Ctrl+D` дублирует со смещением.
- `Ctrl+клик` входит внутрь группы и выбирает отдельный объект.
- `Ctrl+перетаскивание` оранжевого перекрестия меняет центр вращения.
- `Tab` перебирает объекты, `Alt+клик` — объекты под верхним.

## Группы, клоны и повтор

- **Ctrl+G** группирует выделение, **Ctrl+U** разгруппировывает один уровень,
  **Ctrl+Shift+U** расформировывает все вложенные группы.
- Группа выделяется и перемещается как один объект; внутри неё можно выбрать
  отдельный объект через **Ctrl+клик**.
- Групповой поворот и отражение работают вокруг общего центра, который можно
  перемещать (оранжевое перекрестие, `Ctrl+перетаскивание`).
- **Клонировать** (меню «Правка») создаёт связанную копию: изменение заливки,
  формы или текста мастера обновляет клон. Позиция клона остаётся своей.
- **Шаг и повтор** (`Ctrl+Shift+D`) создаёт несколько копий с заданным
  смещением по X/Y.
- **Наклонить…** (меню «Объект») задаёт горизонтальный и вертикальный скос
  в градусах.

## Редактор узлов

Инструмент **«Форма» (N)**:

- добавление узла — **двойной клик по сегменту** или кнопка «Добавить»;
- удаление — **Del** или кнопка «Удалить»;
- выбор нескольких узлов — **Shift+клик**, выравнивание по шести направлениям;
- типы узлов: **тупой, сглаженный, симметричный**;
- направляющие можно тянуть **независимо** друг от друга;
- **замкнуть / разомкнуть** контур;
- **соединить** две кривые и **разорвать** кривую в узле на два объекта;
- все операции участвуют в Undo/Redo.

## Текст

- **Редактирование прямо на холсте**: двойной клик по тексту открывает
  накладной редактор; `Ctrl+Enter` — применить, `Esc` — отменить.
- **Символ…** — шрифт, кегль, полужирный/курсив, подчёркивание,
  зачёркивание, верхний/нижний индекс, трекинг, межсловный интервал,
  горизонтальный и вертикальный масштаб, сдвиг базовой линии.
- **Абзац…** — выравнивание, межстрочный и межабзацный интервалы, отступ
  первой строки, размер текстового блока (перенос строк внутри области).
- **Текст по контуру** — выделите текст и кривую, затем
  **Текст → Текст по контуру**. Работает с любой кривой Безье, включает
  смещение вдоль контура и обратное направление.
- **Текст в фигуре** — выделите текст и фигуру-контейнер, затем
  **Текст → Текст в фигуре**; текст обрезается контуром фигуры.
  **Текст → Отделить текст** возвращает обычный блок.
- **OpenType и оси…** — лигатуры, дискреционные лигатуры, капитель,
  старостильные/табличные цифры, дроби, перечёркнутый ноль; для Variable
  Fonts показываются доступные оси с ползунками значений.
- **Менеджер шрифтов…** — поиск, фильтр по категориям, избранное,
  предпросмотр, список начертаний и информация об осях шрифта.
- **Вставить символ…** — Unicode-символы, включая кириллицу и типографику.
- **Ctrl+Q / Текст → Преобразовать в кривые** переводит текст в контур
  с сохранением заливки, градиента и обводки; текст по контуру и в фигуре
  экспортируется в SVG как настоящие контуры.

Ограничение: независимое форматирование каждого отдельного символа
(произвольные фрагменты внутри одного текстового блока) пока не реализовано;
форматирование применяется к текстовому объекту целиком.

## Логические операции

**Объект → Логические операции**:

- **Объединение** — слить контуры.
- **Вычитание** — вычесть верхние объекты из нижнего.
- **Пересечение** — оставить общую область.
- **Исключение** — убрать области пересечения.
- **Разделение** — разбить пересечения на отдельные области.
- **Обрезка** — обрезать объекты верхним контуром.

Работают с кривыми Безье, составными контурами и отверстиями. Текстовые
объекты автоматически превращаются в контуры. Результат сохраняет заливку,
обводку и слой нижнего объекта. **Ctrl+Q** теперь превращает в кривые не
только текст, но и стандартные фигуры.

## Градиенты

В докерах **«Свойства»** и **«Цвет»** есть кнопка **«Градиент…»**:

- сплошная, линейная, радиальная, **коническая**, **многоточечная**,
  **свободная** и **mesh-заливка (4 угла)**;
- список цветовых точек: добавление, удаление, перетаскивание позиции,
  цвет каждой точки и **собственная прозрачность**;
- угол, центр и радиус градиента;
- градиент применяется к фигурам и тексту и сохраняется в `.vct`;
- экспортируется в SVG настоящими `linearGradient` / `radialGradient`
  со всеми точками и их `stop-opacity`.

## Эффекты и перетекание

Все эффекты **неразрушающие**: геометрия объекта не меняется, параметры
хранятся отдельно, применяются в порядке списка и сохраняются в `.vct`.
Панель **«Эффекты»** (меню «Эффекты» → «Панель эффектов…») показывает
стек: включение галочкой, порядок стрелками `↑`/`↓`, удаление `−`,
добавление через `+` или меню «Эффекты → Векторные эффекты».

| Эффект | Параметры |
| --- | --- |
| Тень | сдвиг X/Y, радиус размытия, прозрачность, цвет |
| Внутренняя тень | сдвиг, радиус, прозрачность, цвет |
| Свечение / внутреннее свечение | радиус, интенсивность, прозрачность, цвет |
| Размытие | радиус |
| Размытие в движении | длина и угол |
| Смещённый контур (Offset Path) | расстояние, цвет, прозрачность |
| Искажение | амплитуда, период, угол |
| Деформация (Warp) | сила и центр радиальной деформации |
| Экструзия | глубина, направление, перспектива, точка схода, освещение, цвет граней |
| Перспектива | четыре угла в процентах от рамки |
| Обтравочная маска / маска прозрачности | геометрия маски, сила |

- **Перетекание** (докер «Эффекты» → вкладка «Перетекание», `Shift+B`):
  между двумя объектами создаются промежуточные копии с интерполяцией
  положения, размера, поворота, цвета заливки/обводки, градиентных точек,
  прозрачности и параметров эффектов. Шаги (2–80) и интервал меняются
  после создания, результат пересобирается автоматически, а перемещение
  или изменение крайнего объекта обновляет перетекание.
- **Экструзия** (`Shift+X`) — протяжка от объекта задаёт глубину и
  направление; боковые грани затеняются по освещению и сходятся к точке
  схода.
- **Перспектива** (`Shift+F`) — маркеры по четырём углам прямо на холсте;
  двойной клик по объекту сбрасывает искажение.
- Несколько эффектов на одном объекте, изменение порядка, отключение и
  удаление; всё входит в Undo/Redo и экспортируется: PNG/PDF/печать
  растрируют эффекты, SVG встраивает сплющенный слой PNG.

## Символы и экземпляры

Меню **«Символы»** и вкладка **«Символы»** в докере «Библиотека»:

- **Создать символ** (`Ctrl+K`) — выделенные объекты (в том числе группа)
  превращаются в символ документа; выделение остаётся на холсте как
  первый экземпляр и получает общую группу.
- **Вставить экземпляр** — подменю «Символы → Вставить символ» или
  двойной щелчок по символу: новый экземпляр ставится в центр страницы.
  Экземпляры можно двигать, вращать и **масштабировать независимо** —
  определение символа при этом не меняется.
- **Обновить символ** (`Ctrl+Shift+K`) — выделите экземпляр, измените его
  обычными инструментами (узлы, цвет, размер) и обновите символ: остальные
  экземпляры пересобираются из нового определения, сохраняя собственные
  положение, размер и поворот.
- **Отделить экземпляр** (`Ctrl+Alt+K`) — объекты перестают следовать
  символу и остаются обычной группой.
- **Переименовать / удалить** — символ хранится в `.vct`; при удалении
  его экземпляры становятся обычными объектами, геометрия не теряется.
- Символы переживают сохранение, загрузку и Undo/Redo; панель показывает
  предпросмотр, число объектов и размещённых экземпляров.

Ограничение: вложенные символы при создании сплющиваются в геометрию
(экземпляр внутри символа становится обычными контурами).

## Библиотека ресурсов

Докер **«Библиотека»** (меню «Библиотека») — общие ресурсы, доступные
всем документам. Хранятся в профиле пользователя и переживают перезапуск.

- **Библиотеки**: переключение списком, `+` — новая, `⤓` — импорт `.vlib`,
  `⤒` — экспорт, `↶`/`↷` — отмена и повтор изменений библиотеки.
- **Категории**: иконки, логотипы, фигуры, декоративные, геометрические,
  текстовые, символы и пользовательские; можно создавать свои.
- **Ресурсы**: добавление выделения (`Ctrl+Shift+L`) или SVG-файла,
  переименование, смена категории, избранное (`★`), удаление, поиск по
  названию и фильтр по категории.
- **Предпросмотр** рисуется из SVG-исходника; **двойной щелчок**
  вставляет ресурс в центр страницы, **перетаскивание** — в точку холста.
- **Копирование** ресурса в другую библиотеку и импорт/экспорт целых
  библиотек в `.vlib` (JSON). Ресурсы хранятся как SVG, поэтому остаются
  векторными и редактируются после вставки.
- Файлы SVG и растровые изображения можно также перетащить на холст
  прямо из файлового менеджера.

## Размеры и точное черчение

Меню **«Черчение»**, инструмент **«Размер»** (`Q`) и панель свойств:

- **Горизонтальный, вертикальный и наклонный** размеры — два щелчка;
  размерная линия ставится с заданным смещением, стрелки и выносные линии
  рисуются автоматически.
- **Угловой размер** — три щелчка: вершина и две точки на сторонах угла.
- **Радиус и диаметр** — щелчок по окружности или эллипсу; лидер проходит
  через центр, значение считается по реальному радиусу.
- **Единицы** мм/см/дюймы/px и **точность** 0–4 знака задаются в панели
  свойств и применяются к выделенным размерам.
- **Связь с объектом**: выносные точки запоминаются как доли рамки объекта.
  При перемещении, изменении размера или узлов размер пересчитывается
  автоматически; кнопка «Применить к выделенным» обновляет единицы,
  точность и смещение.
- Размеры сохраняются в `.vct`, входят в Undo/Redo и экспортируются
  в PNG/PDF/печать (в SVG — сплющенным слоем).

**Точные построения** (меню «Черчение»):

| Команда | Что делает |
| --- | --- |
| Линия по координатам… | линия по двум точкам X/Y |
| Линия по длине и углу… | отрезок заданной длины под углом |
| Параллельная линия… | параллель к выделенной линии со смещением |
| Перпендикуляр… | перпендикуляр заданной длины из середины линии |
| Касательная из точки… | две касательные к выделенному эллипсу |
| Окружность по радиусу… | окружность с центром и радиусом |
| Дуга по радиусу… | дуга по центру, радиусу, началу и развороту |
| Правильный многоугольник… | многоугольник по числу сторон и радиусу |
| Копия со смещением… | точное копирование с шагом X/Y и числом копий |
| Масштабировать выделение… | масштаб выделения на коэффициент |

## Сетки, привязки и масштаб

- **Три системы сетки**: декартова, **полярная** (кольца и лучи) и
  **изометрическая** (линии под 30°). Переключение — «Черчение → Сетка»
  или «Просмотр → Сетка и привязка…».
- Настраиваются шаг, угол полярной сетки, начало координат и
  чувствительность привязки.
- **Умные привязки** к узлам, центрам, серединам, пересечениям рамок,
  ближайшим краям, касаниям (квадрантам эллипсов), направляющим и
  сетке. При срабатывании рисуется маркер и подпись типа привязки
  («Узел», «Центр», «Середина», «Пересечение», «Касание», «Сетка»…).
  Каждая категория включается отдельно.
- **Масштаб чертежа** 1:N («Черчение → Масштаб чертежа…»): значения
  размеров и координаты в статус-баре показывают реальные величины,
  масштаб хранится в `.vct` и отображается в статус-баре.
- Единицы **мм, см, дюймы, px** переключаются в статус-баре; линейки
  следуют выбранным единицам.

## Паттерны и повторения

Меню **«Узор»** и вкладка **«Узоры»** в докере «Библиотека»:

- **Создать узор из выделения** (`Ctrl+Alt+P`) — объекты снимаются в ячейку
  узора и сохраняются в документе.
- **Редактор узора** (`Узор → Редактировать узор…`) с живым предпросмотром:
  ячейка W×H, интервалы X/Y, смещение X/Y, угол, масштаб элементов,
  количество для радиальных повторов, симметрия по X/Y и шаг по кривой.
- **Типы повторения**: сетка, кирпич, шестиугольник, зеркало (4 варианта
  на ячейку), радиальный, поворот вокруг центра и повторение по кривой.
- **Проверка бесшовности** сравнивает противоположные края ячейки и
  показывает процент расхождения; при интервалах узор считается бесшовным.
- **Применение**: узор заливает выделенные фигуры (обрезка по контуру
  объекта), параметры и геометрия ячейки хранятся в объекте и в `.vct`.
- **Редактирование применённого узора** обновляет все объекты с этой
  заливкой; **«Обновить узор из выделения»** заменяет исходные элементы
  узора и пересобирает связанные заливки.
- **Разобрать узор на объекты** превращает повторяющиеся элементы в
  отдельные векторные объекты, обрезанные по форме.
- **Библиотека узоров**: сохранение, превью, применение двойным щелчком,
  удаление, импорт/экспорт `.vpat`; библиотека хранится в профиле и
  доступна всем документам.
- Узоры входят в Undo/Redo и переживают сохранение/загрузку.

## QR-коды и штрихкоды

Меню **«Код»** создаёт машиночитаемые объекты прямо в документе:

- **QR-код** (`Ctrl+Alt+Q`): произвольный текст, URL, контактные данные
  (vCard), уровень коррекции **L/M/Q/H**, размер, цвет, фон и отступ.
  Матрица рисуется векторными квадратами, а не картинкой.
- **EAN-13, EAN-8, UPC-A** — контрольная цифра вычисляется автоматически,
  неверная контрольная цифра во вводе отклоняется; цифры печатаются под
  штрихкодом.
- **Code 128** (ASCII 32–126, автоматический выбор подмножества B/C) и
  **Code 39** (0–9, A–Z, пробел, `-.$/+%`) с контрольной суммой.
- **Data Matrix ECC200** (ASCII, квадратные символы до 26×26).

**Редактор кода** открывается при создании, двойным щелчком по объекту,
из контекстного меню или «Код → Редактировать код…»:

- живой предпросмотр и проверка данных (длина, алфавит, контрольные цифры);
- изменение типа, данных, коррекции, отступа, размеров, цвета и фона;
- повторная генерация при любом изменении, проверка стандартных
  ограничений;
- размеры меняются рамкой, но модули пересчитываются заново и остаются
  квадратными — геометрия кода не искажается произвольно.

Коды хранятся в `.vct` как редактируемые объекты (данные, параметры и
матрица), входят в Undo/Redo, экспортируются в **SVG настоящими
прямоугольниками**, а также в PNG/PDF/печать. При наличии системного
декодера автотест проверяет чтение QR, EAN-13, Code 128 и Code 39.

## Управление документами

- **Автосохранение** (по умолчанию каждые 2 минуты): снимок пишется в профиль
  (`autosave/`) и не трогает исходный файл. Хранится несколько резервных
  копий; после аварийного завершения при запуске появляется предложение
  восстановить последний снимок. Интервал, число копий и включение —
  в «Настройки…».
- **История изменений** («Правка → История изменений…»): список действий
  с названиями и временем, переход к любому состоянию, дальнейшие шаги
  остаются в «Повторить». История до 100 шагов, последние 20 сохраняются
  рядом с документом (`.vct.history.json`) для следующих сеансов.
- **Версии документа** («Файл → Версии документа…»): именованные снимки
  с описанием, восстановление, удаление и сравнение версий или версии
  с текущим состоянием (страницы, слои, объекты по типам, масштаб,
  символы и узоры). Хранятся в `<документ>.vct.versions.json`.
- **Шаблоны** («Файл → Шаблоны документов…»): 9 встроенных шаблонов
  (логотипы, визитки, плакаты, буклеты, иллюстрации, соцсети, упаковка,
  этикетки, презентации) с реальными макетами, предпросмотром, поиском,
  категориями и избранным. Можно сохранить текущий документ как шаблон,
  импортировать/экспортировать `.vtpl`, создать новый документ из шаблона.
- **Поиск объектов** (`Ctrl+F`): по имени, тексту, типу, слою и странице;
  переименование прямо из результатов, переход и выделение на холсте,
  проверка отсутствующих шрифтов и изображений (изображения встроены,
  внешних файлов нет). Объекты можно называть через контекстное меню.
- **Упаковка документа** («Файл → Упаковать документ…»): отдельная папка
  с копией `.vct`, выгруженными изображениями, отчётом о страницах, слоях,
  шрифтах (с напоминанием о лицензии), символах, узорах, контрольной суммой
  SHA-1 и проверкой целостности сохранённой копии.

## Обновления приложения

При запуске Vectora проверяет последний релиз на GitHub
(`pavelvay/vectora`). Если версия новее:

- открывается окно с номером новой версии, списком изменений и выбором
  файла для платформы;
- **«Скачать и установить»** загружает пакет с прогрессом:
  - Linux AppImage заменяет текущий файл и предлагает перезапуск;
  - `.deb` открывается системным установщиком;
  - Windows запускает `Setup.exe`;
  - macOS открывает DMG;
- есть кнопки «Открыть на GitHub» и «Позже»; ошибки сети показываются
  только при ручной проверке.

Ручная проверка — «Справка → Проверить обновления…». Автопроверку можно
отключить в «Настройки…».

## Цвет, палитры и прозрачность

- Цветовые пространства: **RGB, HEX, HSL, HSV (через HSV-слайдеры), CMYK,
  Lab** и альфа-канал; функции конвертации доступны в `Document.h`.
- **Палитры** (меню «Палитры»): добавить цвет заливки, добавить
  **Spot-цвет**, сделать цвет **глобальным**, сохранить/загрузить палитру
  (`.vpal`, `.json`, `.gpl`), экспорт в `.gpl`, сброс.
  Пользовательские, Spot- и глобальные цвета переживают перезапуск.
- Прозрачность объекта, **независимая прозрачность заливки и обводки**,
  режимы наложения (**умножение, экран, перекрытие, затемнение,
  осветление, жёсткий/мягкий свет, разница, исключение** и др.).
- Прозрачность по точкам градиента и корректный экспорт прозрачности в SVG
  (`fill-opacity`, `stroke-opacity`, `stop-opacity`).
- Пипетка по холсту и по цветам объектов.

Ограничения: ICC-профили, цветокоррекция документа и лицензированные
библиотеки коммерческих Spot-каталогов не включены — для них нужна
отдельная интеграция с системами управления цветом и лицензируемыми
каталогами.

## Страницы, мастер-страницы и макеты

Панель страниц находится **внизу, над палитрой цветов** — вкладки
страниц, как в профессиональных редакторах:

- вкладки `1 Обложка`, `2 Разворот`, `3 Визитка` — клик переключает
  страницу; активная подсвечена;
- `◀` / `▶` — предыдущая/следующая страница;
- `+` добавить, `⧉` дублировать (с объектами), `−` удалить;
- двойной клик по вкладке — переименование, правый клик — меню:
  переименовать, дублировать, удалить, **размер страницы**, мастер;
- `★` — мастер-страницы: применить к текущей странице, «Без мастера»,
  «Создать мастер из этой страницы», «Редактировать мастер»;
- при редактировании мастера вкладки скрывают выделение, а кнопка
  `✕ Мастер: имя` возвращает к страницам;
- объекты мастер-страницы рисуются позади содержимого всех связанных
  страниц и не выделяются на обычных страницах.

**Объект → Размер страницы…** (или контекстное меню страницы) задаёт для
каждой страницы: формат **A0–A6, Letter, Legal, Tabloid**, свой размер,
ориентацию, единицы **px/мм/см/in/pt**, цвет фона, поля и вылеты под обрез.
Вылеты и поля показываются пунктиром на холсте.

## Направляющие и привязка

- Потяните от **горизонтальной линейки** вниз — появится горизонтальная
  направляющая; от **вертикальной** вправо — вертикальная.
- Направляющие сохраняются в документе и участвуют в Undo/Redo.
- **Просмотр → Направляющие** скрывает/показывает их,
  **Удалить направляющие** очищает все.
- Сетка и область печати по умолчанию **выключены**; включаются
  в меню «Просмотр».
- **«Привязка»** работает к:
  - сетке с настраиваемым шагом;
  - направляющим;
  - краям и центру страницы;
  - краям и центрам других объектов;
  - узлам других контуров.
- При срабатывании рисуются **умные направляющие** (розовые линии).
- **Просмотр → Сетка и привязка…** задаёт шаг сетки и чувствительность
  привязки.

## Импорт SVG

SVG больше не растеризуется. Импортируются:

- отдельные объекты: `path`, `rect`, `circle`, `ellipse`, `line`,
  `polyline`, `polygon`, `text`;
- вложенные группы и трансформации;
- заливки, обводки, прозрачность;
- линейные и радиальные градиенты;
- текст с шрифтом, размером и выравниванием;
- размер страницы из `width/height` и `viewBox`.

Ограничения: дуги `A` аппроксимируются отрезками, не поддерживаются
`clipPath`, `mask`, `use`, `symbol`, фильтры и CSS-классы. Слои SVG
импортируются как один новый слой, группы сохраняются.

## Меню «Объект»

- Порядок: на передний/задний план, на уровень выше/ниже (внутри слоя).
- Отразить по горизонтали и вертикали.
- Повернуть на 90°.
- Выравнивание доступно в докере «Выравнивание».
- «Эффекты → Тень/Прозрачность/Перетекание» открывают нужную вкладку докера.

## Новый документ

При **Ctrl+N** и на стартовой странице открывается диалог:

- форматы **A4, A3, A2, 1920 × 1080** или **свой размер**;
- ориентация книжная/альбомная;
- единицы **px, мм, см, дюймы**;
- размер можно ввести вручную.

По умолчанию новый документ открывается **без сетки** и **без синей
пунктирной области печати**. Обе опции включаются в меню «Просмотр».
Единицы также переключаются в статус-баре.

## Правая кнопка мыши

На объекте:

- вырезать, копировать, дублировать, клонировать, удалить;
- сгруппировать/разгруппировать;
- порядок: на передний/задний план, выше/ниже;
- отразить, повернуть, наклонить;
- преобразовать текст в кривые;
- заблокировать/разблокировать объект;
- открыть докер «Свойства».

На пустом холсте:

- отменить/повторить, вставить, выделить всё;
- сетка, направляющие, область печати, привязка, линейки;
- по размеру страницы, 100 %;
- сетка и привязка…, размер страницы….

## Главная страница

При запуске открывается стартовый экран:

- **Новый документ** — пустая страница A4.
- **Открыть файл** — `.vct` или импорт SVG/изображения.
- **Недавние документы** — до 8 последних открытых и сохранённых файлов,
  хранятся между запусками.
- **Демонстрационный документ** — пример со слоями и объектами.
- Вернуться на главную можно через **Файл → Главная страница**
  (`Ctrl+Shift+H`).

## Слои

- Кнопка **+ Слой** создаёт новый слой сверху и делает его активным.
- Активный слой отмечен точкой **●**; новые объекты рисуются в него.
- Объекты перетаскиваются мышью на другой слой или в нужное место слоя.
- Кнопки **Выше/Ниже** меняют порядок объекта в слое, а для выбранного слоя —
  порядок самих слоёв.
- Список **Слой → Перенести** переносит выделенные объекты в выбранный слой.
- **− Слой** удаляет слой вместе с объектами (с подтверждением).
- Двойной клик по имени слоя переименовывает его.
- У каждого объекта в списке есть **свой замок**: заблокированный объект
  нельзя выделить и сдвинуть, пока замок не снят.
- Слои и замки сохраняются в `.vct`, участвуют в Undo/Redo.

| Экструзия `Shift+X` | объёмное продолжение, протяжка задаёт глубину и угол |
| Перспектива `Shift+F` | маркеры четырёх углов, двойной клик — сброс |
| Масштаб `Z` | клик — увеличить, правый клик — уменьшить |
| Панорама `H` | перетаскивание холста |

## Файлы

- `.vct` — собственный JSON-формат: страницы, мастер-страницы, слои,
  геометрия, градиенты и их точки, шрифты и типографика, эффекты и их стек,
  перетекания, символы и их экземпляры, размеры, масштаб чертежа, узоры и их ячейки, QR/штрихкоды, тени, картинки. Рядом могут лежать `.vct.history.json` и `.vct.versions.json`.
- Импорт PNG, JPG, BMP, SVG.
- Экспорт PNG (2×) и SVG текущей страницы с настоящими путями и текстом.
- **Экспорт PDF — все страницы одним файлом**.
- **Экспорт всех страниц в PNG** с выбором масштаба/разрешения.
- Печать — все страницы (QPrintDialog, масштаб по листу).
- Undo/Redo до 100 шагов, история и именованные версии документа.
- Автосохранение в профиле, шаблоны `.vtpl`, упаковка проекта.
- Копирование, вырезание, вставка, дублирование.

## Обмен с другими редакторами

Для переноса макетов используйте **SVG** и **PDF**:

- **SVG** сохраняет векторную геометрию, текст и градиенты; слои при
  экспорте сплющиваются, но контуры и текст остаются редактируемыми
  в принимающей программе.
- **PDF** подходит для печати и просмотра; все страницы документа
  экспортируются одним файлом.
- Проприетарные форматы закрыты, их импорт и экспорт не поддерживаются.

## Что пока не реализовано

- Импорт и экспорт проприетарных форматов других редакторов.
- Отдельные докеры «Линза» и «Фаска»: сейчас размытие и внутренняя тень доступны в общей панели эффектов; фигурная обрезка — через обтравочную маску.
- ICC-профили и цветокоррекция документа, лицензируемые Spot-каталоги.
- Независимое форматирование произвольных фрагментов внутри одного
  текстового блока (сейчас — на весь текстовый объект).
- Обтекание текста объектами, связанные текстовые блоки с автоматическим
  перетеканием и модульные сетки/колонки макета.
- Точный обмен многостраничными SVG (экспорт — по одной странице),
  `mask`, `clipPath`, `use`, фильтры и CSS-классы в SVG.
- Маркеры масштаба группы вокруг всей группы (масштаб — через «Свойства»).
- Отдельные докеры «Стили», «Линза», «Фаска» (эффекты собраны в одной панели).
- Вложенные символы: экземпляр внутри символа сплющивается в контуры.
- Размеры не поддерживают допуски, цепочки и суммарные размеры.
- Узорная заливка применяется к фигурам; текст сохраняет обычную заливку.
- Повторение по кривой использует плавную волну через объект; пользовательская направляющая хранится в узоре, но пока не выбирается из интерфейса.
- QR поддерживает версии 1–10 (до 271 байта при коррекции L), Data Matrix — до 26×26 (до 44 байт ASCII). Code 128: ASCII 32–126. GS1, PDF417 и Aztec не включены.

- Интерактивные маркеры наклона и отдельные маркеры группы
  (наклон — числовой диалог, группа масштабируется через «Свойства»).

## Windows и macOS

Код и CMake-проект кроссплатформенные. Для сборки достаточно Qt 6 и CMake:

- **Windows**: Qt Online Installer (MSVC 2022 + Qt 6), затем
  `cmake -S . -B build -G "Visual Studio 17 2022" -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/msvc2022_64`.
- **macOS**: `brew install qt cmake`, затем
  `cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"`.

Упаковка (AppImage/Flatpak, MSI/MSIX, DMG с подписью) — отдельный этап.
