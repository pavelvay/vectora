# Vectora

Кроссплатформенный векторный редактор на **C++17 и Qt 6** (Qt Widgets).
Рабочее название проекта, легко меняется.

Десятый этап: **форматы листа при создании**, **правая кнопка мыши**
на объектах и пустом холсте, **чистый холст без сетки и области печати**
по умолчанию.

## Установка

Готовые сборки публикуются в GitHub Releases: Windows-установщик, Linux
AppImage и `.deb`, macOS DMG.

- **Windows**: скачайте `Vectora-0.1.11-Setup.exe` и запустите. Сборка не
  подписана, поэтому SmartScreen может показать предупреждение:
  «Подробнее» → «Выполнить в любом случае».
- **Linux AppImage**: `chmod +x Vectora-0.1.11-x86_64.AppImage` и запустите.
  Если нет FUSE: `./Vectora-0.1.11-x86_64.AppImage --appimage-extract-and-run`.
  AppImage использует X11/XWayland; при необходимости задайте
  `QT_QPA_PLATFORM=xcb`.
- **Debian/Ubuntu**: `sudo apt install ./Vectora-0.1.11-amd64.deb`.
- **Arch/CachyOS**: `packaging/PKGBUILD` — `makepkg -si`.
- **macOS (Apple Silicon)**: откройте DMG и перетащите Vectora в Applications.
  Сборка не подписана: правый клик → «Открыть» или
  `xattr -dr com.apple.quarantine /Applications/Vectora.app`.
  DMG собран для arm64 (Apple Silicon); для Intel Mac нужна отдельная сборка.

Сборки создаются автоматически в GitHub Actions.

## Сборка (Linux)

Нужны CMake ≥ 3.21, компилятор C++17 и Qt 6 (Base, Widgets, Svg, PrintSupport).

Arch / CachyOS / Manjaro:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg
```

Debian / Ubuntu (24.04+):

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
```

Fedora:

```bash
sudo dnf install gcc-c++ cmake qt6-qtbase-devel qt6-qtsvg-devel
```

Сборка и запуск:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/vectora
```

Для локальной проверки используйте `./run.sh` — он **всегда пересобирает
локально** изменённый код и запускает приложение, ничего не публикуя:

```bash
./run.sh                 # Release-сборка + запуск
./run.sh --debug         # Debug-сборка + запуск
./run.sh --test          # автотесты без окна
./run.sh --no-build      # запустить уже собранный бинарник
./run.sh --clean         # очистить build/ и собрать заново
```

Скрипт никогда не создаёт теги, релизы и не выгружает файлы на GitHub.
Публикация выполняется только по отдельному запросу на сборку.

## Кривая Безье

Поведение приближено к CorelDRAW:

- **Клик** ставит узел; **протяжка** от узла задаёт кривизну сегмента.
- **Alt** при протяжке делает узел тупым (направляющие независимы).
- **Ctrl** ограничивает направляющую шагом 15°.
- **Backspace** удаляет последний узел.
- **Клик по первому узлу** замыкает кривую (узел подсвечивается).
- **Enter** или **двойной клик** завершает открытую кривую.
- **Esc** отменяет построение.
- В панели свойств сверху выбирается тип нового узла:
  тупой, сглаженный или симметричный; есть «Автозамыкание»,
  «Замкнуть», «Удалить узел» и «Завершить».
- Замкнутая кривая получает заливку, открытая остаётся контуром.

## Докеры справа

Все панели докируемые, с вкладками, как в CorelDRAW. Снизу справа —
группы вкладок, сверху список объектов.

| Докер | Что делает |
| --- | --- |
| **Объекты** | слои, **вложенные группы**, объекты; перетаскивание, видимость, замки слоёв и объектов |
| **Свойства** | X, Y, ширина, высота, угол, прозрачность, заливка, обводка, толщина — применяются сразу; прозрачность в реальном времени |
| **Цвет** | оттенок/насыщенность/яркость/альфа и HTML-код; заливка применяется сразу, ЛКМ по образцу — заливка, ПКМ — обводка |
| **Выравнивание** | 6 выравниваний относительно выделения или страницы, распределение по горизонтали и вертикали |
| **Эффекты → Тень** | включение, сдвиг X/Y, непрозрачность, цвет тени |
| **Эффекты → Прозрачность** | прозрачность выделения, применяется сразу при движении ползунка |
| **Эффекты → Перетекание** | 2–40 промежуточных копий между двумя объектами |
| **Обводка** | цвет, толщина, окончания, соединения, miter-limit, пунктир; преобразование обводки в кривую |
| **Текст** | шрифт, кегль, полужирный/курсив/подчёркивание, выравнивание |

Верхняя панель быстрых свойств синхронизирована с выделением,
как контекстная панель CorelDRAW.

## Параметры фигур

Для инструментов фигур верхняя панель показывает параметры, как в CorelDRAW:

- **Прямоугольник** — скругление углов;
- **Многоугольник** — число сторон (3–64);
- **Звезда** — число лучей и острота;
- **Спираль** — число витков.

Значение применяется к выделенным фигурам этого типа и запоминается
для новых. Размер фигуры при смене параметра сохраняется.

## Выделение как в CorelDRAW

- Угловой маркер масштабирует **пропорционально**; боковой — свободно.
  `Shift` при протяжке угла отключает пропорции.
- `Ctrl` (или `Shift`) при повороте фиксирует угол кратно 15°.
- `Alt+клик` выбирает объект **под** верхним; повторный Alt+клик уходит глубже.
- `Tab` перебирает объекты сверху вниз.
- Двойной клик по инструменту **«Выделение»** выбирает все объекты.
- `Ctrl+V` вставляет объект **точно на исходное место**, как в CorelDRAW.
- `Ctrl+D` дублирует со смещением.
- `Ctrl+клик` входит внутрь группы и выбирает отдельный объект.
- `Ctrl+перетаскивание` оранжевого перекрестия меняет центр вращения.
- `Tab` перебирает объекты, `Alt+клик` — объекты под верхним.

## Группы, клоны и повтор

- **Ctrl+G** группирует выделение, **Ctrl+U** разгруппировывает один уровень,
  **Ctrl+Shift+U** расформировывает все вложенные группы.
- Группа выделяется и перемещается как один объект; внутри неё можно выбрать
  отдельный объект через **Ctrl+клик**.
- Групповой поворот и отражение работают вокруг общего центра, который можно
  перемещать (оранжевое перекрестие, `Ctrl+перетаскивание`).
- **Клонировать** (меню «Правка») создаёт связанную копию: изменение заливки,
  формы или текста мастера обновляет клон. Позиция клона остаётся своей.
- **Шаг и повтор** (`Ctrl+Shift+D`) создаёт несколько копий с заданным
  смещением по X/Y.
- **Наклонить…** (меню «Объект») задаёт горизонтальный и вертикальный скос
  в градусах.

## Редактор узлов

Инструмент **«Форма» (N)**:

- добавление узла — **двойной клик по сегменту** или кнопка «Добавить»;
- удаление — **Del** или кнопка «Удалить»;
- выбор нескольких узлов — **Shift+клик**, выравнивание по шести направлениям;
- типы узлов: **тупой, сглаженный, симметричный**;
- направляющие можно тянуть **независимо** друг от друга;
- **замкнуть / разомкнуть** контур;
- **соединить** две кривые и **разорвать** кривую в узле на два объекта;
- все операции участвуют в Undo/Redo.

## Текст

- **Редактирование прямо на холсте**: двойной клик по тексту открывает
  накладной редактор; `Ctrl+Enter` — применить, `Esc` — отменить.
- **Символ…** — шрифт, кегль, полужирный/курсив, подчёркивание,
  зачёркивание, верхний/нижний индекс, трекинг, межсловный интервал,
  горизонтальный и вертикальный масштаб, сдвиг базовой линии.
- **Абзац…** — выравнивание, межстрочный и межабзацный интервалы, отступ
  первой строки, размер текстового блока (перенос строк внутри области).
- **Текст по контуру** — выделите текст и кривую, затем
  **Текст → Текст по контуру**. Работает с любой кривой Безье, включает
  смещение вдоль контура и обратное направление.
- **Текст в фигуре** — выделите текст и фигуру-контейнер, затем
  **Текст → Текст в фигуре**; текст обрезается контуром фигуры.
  **Текст → Отделить текст** возвращает обычный блок.
- **OpenType и оси…** — лигатуры, дискреционные лигатуры, капитель,
  старостильные/табличные цифры, дроби, перечёркнутый ноль; для Variable
  Fonts показываются доступные оси с ползунками значений.
- **Менеджер шрифтов…** — поиск, фильтр по категориям, избранное,
  предпросмотр, список начертаний и информация об осях шрифта.
- **Вставить символ…** — Unicode-символы, включая кириллицу и типографику.
- **Ctrl+Q / Текст → Преобразовать в кривые** переводит текст в контур
  с сохранением заливки, градиента и обводки; текст по контуру и в фигуре
  экспортируется в SVG как настоящие контуры.

Ограничение: независимое форматирование каждого отдельного символа
(произвольные фрагменты внутри одного текстового блока) пока не реализовано;
форматирование применяется к текстовому объекту целиком.

## Логические операции

**Объект → Логические операции**:

- **Объединение** — слить контуры.
- **Вычитание** — вычесть верхние объекты из нижнего.
- **Пересечение** — оставить общую область.
- **Исключение** — убрать области пересечения.
- **Разделение** — разбить пересечения на отдельные области.
- **Обрезка** — обрезать объекты верхним контуром.

Работают с кривыми Безье, составными контурами и отверстиями. Текстовые
объекты автоматически превращаются в контуры. Результат сохраняет заливку,
обводку и слой нижнего объекта. **Ctrl+Q** теперь превращает в кривые не
только текст, но и стандартные фигуры.

## Градиенты

В докерах **«Свойства»** и **«Цвет»** есть кнопка **«Градиент…»**:

- сплошная, линейная, радиальная, **коническая**, **многоточечная**,
  **свободная** и **mesh-заливка (4 угла)**;
- список цветовых точек: добавление, удаление, перетаскивание позиции,
  цвет каждой точки и **собственная прозрачность**;
- угол, центр и радиус градиента;
- градиент применяется к фигурам и тексту и сохраняется в `.vct`;
- экспортируется в SVG настоящими `linearGradient` / `radialGradient`
  со всеми точками и их `stop-opacity`.

## Цвет, палитры и прозрачность

- Цветовые пространства: **RGB, HEX, HSL, HSV (через HSV-слайдеры), CMYK,
  Lab** и альфа-канал; функции конвертации доступны в `Document.h`.
- **Палитры** (меню «Палитры»): добавить цвет заливки, добавить
  **Spot-цвет**, сделать цвет **глобальным**, сохранить/загрузить палитру
  (`.vpal`, `.json`, GIMP `.gpl`), экспорт в `.gpl`, сброс.
  Пользовательские, Spot- и глобальные цвета переживают перезапуск.
- Прозрачность объекта, **независимая прозрачность заливки и обводки**,
  режимы наложения (**умножение, экран, перекрытие, затемнение,
  осветление, жёсткий/мягкий свет, разница, исключение** и др.).
- Прозрачность по точкам градиента и корректный экспорт прозрачности в SVG
  (`fill-opacity`, `stroke-opacity`, `stop-opacity`).
- Пипетка по холсту и по цветам объектов.

Ограничения: ICC-профили, цветокоррекция документа и лицензированные
библиотеки Spot-цветов (PANTONE и т. п.) не включены — для них нужна
отдельная интеграция с LittleCMS и лицензируемыми каталогами.

## Страницы, мастер-страницы и макеты

Панель страниц находится **внизу, над палитрой цветов** — как вкладки
страниц в CorelDRAW и Visio:

- вкладки `1 Обложка`, `2 Разворот`, `3 Визитка` — клик переключает
  страницу; активная подсвечена;
- `◀` / `▶` — предыдущая/следующая страница (как в CorelDRAW);
- `+` добавить, `⧉` дублировать (с объектами), `−` удалить;
- двойной клик по вкладке — переименование, правый клик — меню:
  переименовать, дублировать, удалить, **размер страницы**, мастер;
- `★` — мастер-страницы: применить к текущей странице, «Без мастера»,
  «Создать мастер из этой страницы», «Редактировать мастер»;
- при редактировании мастера вкладки скрывают выделение, а кнопка
  `✕ Мастер: имя` возвращает к страницам;
- объекты мастер-страницы рисуются позади содержимого всех связанных
  страниц и не выделяются на обычных страницах.

**Объект → Размер страницы…** (или контекстное меню страницы) задаёт для
каждой страницы: формат **A0–A6, Letter, Legal, Tabloid**, свой размер,
ориентацию, единицы **px/мм/см/in/pt**, цвет фона, поля и вылеты под обрез.
Вылеты и поля показываются пунктиром на холсте.

## Направляющие и привязка

- Потяните от **горизонтальной линейки** вниз — появится горизонтальная
  направляющая; от **вертикальной** вправо — вертикальная.
- Направляющие сохраняются в документе и участвуют в Undo/Redo.
- **Просмотр → Направляющие** скрывает/показывает их,
  **Удалить направляющие** очищает все.
- Сетка и область печати по умолчанию **выключены**; включаются
  в меню «Просмотр».
- **«Привязка»** работает к:
  - сетке с настраиваемым шагом;
  - направляющим;
  - краям и центру страницы;
  - краям и центрам других объектов;
  - узлам других контуров.
- При срабатывании рисуются **умные направляющие** (розовые линии).
- **Просмотр → Сетка и привязка…** задаёт шаг сетки и чувствительность
  привязки.

## Импорт SVG

SVG больше не растеризуется. Импортируются:

- отдельные объекты: `path`, `rect`, `circle`, `ellipse`, `line`,
  `polyline`, `polygon`, `text`;
- вложенные группы и трансформации;
- заливки, обводки, прозрачность;
- линейные и радиальные градиенты;
- текст с шрифтом, размером и выравниванием;
- размер страницы из `width/height` и `viewBox`.

Ограничения: дуги `A` аппроксимируются отрезками, не поддерживаются
`clipPath`, `mask`, `use`, `symbol`, фильтры и CSS-классы. Слои SVG
импортируются как один новый слой, группы сохраняются.

## Меню «Объект»

- Порядок: на передний/задний план, на уровень выше/ниже (внутри слоя).
- Отразить по горизонтали и вертикали.
- Повернуть на 90°.
- Выравнивание доступно в докере «Выравнивание».
- «Эффекты → Тень/Прозрачность/Перетекание» открывают нужную вкладку докера.

## Новый документ

При **Ctrl+N** и на стартовой странице открывается диалог:

- форматы **A4, A3, A2, 1920 × 1080** или **свой размер**;
- ориентация книжная/альбомная;
- единицы **px, мм, см, дюймы**;
- размер можно ввести вручную.

По умолчанию новый документ открывается **без сетки** и **без синей
пунктирной области печати**. Обе опции включаются в меню «Просмотр».
Единицы также переключаются в статус-баре.

## Правая кнопка мыши

На объекте:

- вырезать, копировать, дублировать, клонировать, удалить;
- сгруппировать/разгруппировать;
- порядок: на передний/задний план, выше/ниже;
- отразить, повернуть, наклонить;
- преобразовать текст в кривые;
- заблокировать/разблокировать объект;
- открыть докер «Свойства».

На пустом холсте:

- отменить/повторить, вставить, выделить всё;
- сетка, направляющие, область печати, привязка, линейки;
- по размеру страницы, 100 %;
- сетка и привязка…, размер страницы….

## Главная страница

При запуске открывается стартовый экран, как в CorelDRAW и Illustrator:

- **Новый документ** — пустая страница A4.
- **Открыть файл** — `.vct` или импорт SVG/изображения.
- **Недавние документы** — до 8 последних открытых и сохранённых файлов,
  хранятся между запусками.
- **Демонстрационный документ** — пример со слоями и объектами.
- Вернуться на главную можно через **Файл → Главная страница**
  (`Ctrl+Shift+H`).

## Слои

- Кнопка **+ Слой** создаёт новый слой сверху и делает его активным.
- Активный слой отмечен точкой **●**; новые объекты рисуются в него.
- Объекты перетаскиваются мышью на другой слой или в нужное место слоя.
- Кнопки **Выше/Ниже** меняют порядок объекта в слое, а для выбранного слоя —
  порядок самих слоёв.
- Список **Слой → Перенести** переносит выделенные объекты в выбранный слой.
- **− Слой** удаляет слой вместе с объектами (с подтверждением).
- Двойной клик по имени слоя переименовывает его.
- У каждого объекта в списке есть **свой замок**: заблокированный объект
  нельзя выделить и сдвинуть, пока замок не снят.
- Слои и замки сохраняются в `.vct`, участвуют в Undo/Redo.

## Файлы

- `.vct` — собственный JSON-формат: страницы, мастер-страницы, слои,
  геометрия, градиенты и их точки, шрифты и типографика, тени, картинки.
- Импорт PNG, JPG, BMP, SVG.
- Экспорт PNG (2×) и SVG текущей страницы с настоящими путями и текстом.
- **Экспорт PDF — все страницы одним файлом**.
- **Экспорт всех страниц в PNG** с выбором масштаба/разрешения.
- Печать — все страницы (QPrintDialog, масштаб по листу).
- Undo/Redo до 100 шагов.
- Копирование, вырезание, вставка, дублирование.

## CorelDRAW (.cdr)

Формат CDR — закрытый двоичный формат Corel. Единственная открытая
библиотека `libcdr` (её используют LibreOffice и Inkscape) умеет **только
читать** CDR; библиотек записи CDR в открытом ПО нет. Поэтому:

- **импорт и экспорт `.cdr` пока не поддерживаются**;
- для обмена с CorelDRAW используйте **SVG** или **PDF** — CorelDRAW
  открывает оба формата; SVG не хранит слои, они при экспорте сплющиваются,
  но геометрия и текст остаются векторными;
- настоящий экспорт `.cdr` возможен только через установленный CorelDRAW
  (автоматизация COM на Windows) или коммерческий SDK; на Linux без Corel
  это невозможно.

## Что пока не реализовано

- Импорт/экспорт CDR (см. раздел выше).
- Экструзия, линза, фаска и фигурная обрезка (меню «Эффекты»).
- ICC-профили и цветокоррекция документа, лицензируемые Spot-каталоги.
- Независимое форматирование произвольных фрагментов внутри одного
  текстового блока (сейчас — на весь текстовый объект).
- Обтекание текста объектами, связанные текстовые блоки с автоматическим
  перетеканием и модульные сетки/колонки макета.
- Точный обмен многостраничными SVG (экспорт — по одной странице),
  `mask`, `clipPath`, `use`, фильтры и CSS-классы в SVG.
- Маркеры масштаба группы вокруг всей группы (масштаб — через «Свойства»).
- Отдельные докеры «Стили», «Линза», «Фаска».

- Интерактивные маркеры наклона и отдельные маркеры группы
  (наклон — числовой диалог, группа масштабируется через «Свойства»).

## Тесты

Автотест проверяет `.vct` со слоями, экспорт PNG/SVG/PDF, фигуры, заливку,
узлы, тень, перетекание, Bezier (замыкание и Enter), Undo/Redo, слои
(создание, перенос и удаление слоёв, порядок), автозаливку из докера
«Цвет», живую прозрачность, видимость и замок слоёв, замок объектов,
группы и вложенность, клоны, шаг и повтор, наклон, центр вращения,
градиенты, направляющие и привязку, редактор узлов, текст с интервалами
и переводом в кривые, редактируемый импорт SVG:

```bash
QT_QPA_PLATFORM=offscreen ./build/vectora --self-test /tmp/vectora-test
```

## Windows и macOS

Код и CMake-проект кроссплатформенные. Для сборки достаточно Qt 6 и CMake:

- **Windows**: Qt Online Installer (MSVC 2022 + Qt 6), затем
  `cmake -S . -B build -G "Visual Studio 17 2022" -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/msvc2022_64`.
- **macOS**: `brew install qt cmake`, затем
  `cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"`.

Упаковка (AppImage/Flatpak, MSI/MSIX, DMG с подписью) — отдельный этап.
