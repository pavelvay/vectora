# Vectora

Кроссплатформенный векторный редактор на **C++17 и Qt 6** (Qt Widgets).
Рабочее название проекта, легко меняется.

Третий этап: **Bezier как в CorelDRAW** и **докеры справа** — свойства,
цвет, выравнивание, эффекты, обводка и текст. Документы, рисование,
Undo/Redo и экспорт работают.

## Сборка (Linux)

Нужны CMake ≥ 3.21, компилятор C++17 и Qt 6 (Base, Widgets, Svg, PrintSupport).

Arch / CachyOS / Manjaro:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg
```

Debian / Ubuntu (24.04+):

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
```

Fedora:

```bash
sudo dnf install gcc-c++ cmake qt6-qtbase-devel qt6-qtsvg-devel
```

Сборка и запуск:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/vectora
```

Или `./run.sh` — соберёт при первом запуске и откроет редактор.

## Кривая Безье

Поведение приближено к CorelDRAW:

- **Клик** ставит узел; **протяжка** от узла задаёт кривизну сегмента.
- **Alt** при протяжке делает узел тупым (направляющие независимы).
- **Ctrl** ограничивает направляющую шагом 15°.
- **Backspace** удаляет последний узел.
- **Клик по первому узлу** замыкает кривую (узел подсвечивается).
- **Enter** или **двойной клик** завершает открытую кривую.
- **Esc** отменяет построение.
- В панели свойств сверху выбирается тип нового узла:
  тупой, сглаженный или симметричный; есть «Автозамыкание»,
  «Замкнуть», «Удалить узел» и «Завершить».
- Замкнутая кривая получает заливку, открытая остаётся контуром.

## Докеры справа

Все панели докируемые, с вкладками, как в CorelDRAW. Снизу справа —
группы вкладок, сверху список объектов.

| Докер | Что делает |
| --- | --- |
| **Объекты** | живой список объектов; выбор, поднять/опустить, дублировать, удалить |
| **Свойства** | X, Y, ширина, высота, угол, прозрачность, заливка, обводка, толщина — применяются сразу |
| **Цвет** | оттенок/насыщенность/яркость/альфа, HTML-код, залить или обвести выделение |
| **Выравнивание** | 6 выравниваний относительно выделения или страницы, распределение по горизонтали и вертикали |
| **Эффекты → Тень** | включение, сдвиг X/Y, непрозрачность, цвет тени |
| **Эффекты → Прозрачность** | прозрачность выделения |
| **Эффекты → Перетекание** | 2–40 промежуточных копий между двумя объектами |
| **Обводка** | цвет, толщина, применить или убрать обводку |
| **Текст** | шрифт, кегль, полужирный/курсив/подчёркивание, выравнивание |

Верхняя панель быстрых свойств синхронизирована с выделением,
как контекстная панель CorelDRAW.

## Инструменты левой панели

| Инструмент | Что делает |
| --- | --- |
| Выделение `V` | выбор, перемещение, 8 маркеров размера, поворот за верхний круг |
| Форма `N` | редактирование узлов и управляющих точек кривых |
| Обрезка `C` | рамкой обрезает страницу и замкнутые фигуры |
| Прямоугольник `R` | протяжка, `Shift` — квадрат |
| Эллипс `E` | протяжка, `Shift` — круг |
| Многоугольник `P` | от центра, 6 сторон |
| Звезда `Shift+P` | от центра, 5 лучей |
| Спираль `Shift+S` | от центра, 3 оборота |
| Линия `L` | протяжка, `Shift` — 45° |
| Кривая Безье `B` | см. раздел выше |
| Свободная форма `F` | рисование от руки со сглаживанием |
| Художественное перо `A` | толстый мазок цветом заливки |
| Текст `T` | клик создаёт текст, двойной клик — правка |
| Пипетка `I` | берёт цвет с холста |
| Заливка `G` | клик по объекту текущим цветом |
| Обводка `O` | диалог цвета и толщины |
| Прозрачность `Shift+T` | протяжка влево/вправо меняет прозрачность |
| Тень `Shift+D` | включает/выключает тень объекта |
| Перетекание `Shift+B` | 7 промежуточных копий между двумя объектами |
| Масштаб `Z` | клик — увеличить, правый клик — уменьшить |
| Панорама `H` | перетаскивание холста |

## Файлы

- `.vct` — собственный JSON-формат: геометрия, цвета, шрифты, тени, картинки.
- Импорт PNG, JPG, BMP, SVG (SVG пока растеризуется).
- Экспорт PNG (2×) и SVG с настоящими путями и текстом.
- Экспорт PDF (A4 без полей) и печать.
- Undo/Redo до 100 шагов.
- Копирование, вырезание, вставка, дублирование.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` | создать / открыть |
| `Ctrl+S` / `Ctrl+Shift+S` | сохранить / сохранить как |
| `Ctrl+I` / `Ctrl+E` | импорт / экспорт |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | вырезать / копировать / вставить |
| `Ctrl+D` / `Del` | дублировать / удалить |
| `Ctrl+A` | выделить всё |
| `Ctrl + колесо` | масштаб под курсором |
| `Ctrl+0` / `Ctrl+1` / `Ctrl+2` | по странице / 100 % / по выделению |
| `Ctrl+R` | линейки |
| `F11` | полный экран |

Полный список — в меню «Справка → Горячие клавиши» (`Ctrl+F1`),
включая управление Bezier.

## Что пока не реализовано

- Группировка, слои и порядок наложения (меню «Объект»).
- Оболочка, экструзия, линза, скос (меню «Эффекты»).
- Отдельные докеры «Фаска», «Фигурная обрезка», «Линза», «Стили».
- Направляющие и привязка (галочки в меню декоративные).
- Импорт CDR и редактируемый импорт SVG.
- Inline-редактирование текста на холсте (сейчас диалог).

## Тесты

Автотест проверяет `.vct`, экспорт PNG/SVG/PDF, фигуры, заливку, узлы,
тень, перетекание, Bezier (замыкание и Enter), Undo/Redo и применение
свойств из докера:

```bash
QT_QPA_PLATFORM=offscreen ./build/vectora --self-test /tmp/vectora-test
```

## Служебное

```bash
./build/vectora --open файл.vct
QT_QPA_PLATFORM=offscreen ./build/vectora --screenshot /tmp/vectora.png
QT_QPA_PLATFORM=offscreen ./build/vectora --docker "Цвет" --select 0
```

## Windows и macOS

Код и CMake-проект кроссплатформенные. Для сборки достаточно Qt 6 и CMake:

- **Windows**: Qt Online Installer (MSVC 2022 + Qt 6), затем
  `cmake -S . -B build -G "Visual Studio 17 2022" -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/msvc2022_64`.
- **macOS**: `brew install qt cmake`, затем
  `cmake -S . -B build -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"`.

Упаковка (AppImage/Flatpak, MSI/MSIX, DMG с подписью) — отдельный этап.
